🔒 Anmelden auf der Website

So gelangen Sie in den geschuetzten Bereich

1

Website oeffnen

Oeffnen Sie Ihren Browser (Chrome, Firefox, Safari oder Edge) und geben Sie in die Adressleiste ein:

www.rosenweg4303.ch

Tipp: Sie koennen die Adresse auch als Lesezeichen speichern, damit Sie sie nicht jedes Mal eingeben muessen.

2

Auf "Anmelden" klicken

In der Navigation oben rechts sehen Sie den blauen Button "Anmelden". Klicken Sie darauf.

Rosenweg Start Gebaeude ▾ Infos ▾ Kontakt
Anmelden

↑ Die Navigation vor dem Anmelden

Auf dem Handy: Tippen Sie oben rechts auf das Menu-Symbol (☰ drei Striche), dann erscheint "Anmelden" ganz unten.

3

Benutzername und Passwort eingeben

Sie werden zur Anmeldeseite weitergeleitet. Geben Sie dort ein:

vorname.nachname@beispiel.ch
••••••••
Anmelden

Passwort vergessen? Auf der Authentik-Anmeldeseite gibt es den Link «Passwort vergessen?» — dort Ihre E-Mail-Adresse eingeben, Sie erhalten umgehend einen Reset-Link per E-Mail. Falls die E-Mail nicht ankommt oder Sie keine hinterlegte E-Mail haben, melden Sie sich bei technik@rosenweg4303.ch.

✓

Fertig!

Sie sind jetzt angemeldet. Die Navigation aendert sich:

Rosenweg Start Gebaeude ▾ Services ▾ Infos ▾ Kontakt
Hans Muster Abmelden

↑ Nach dem Anmelden: Ihr Name erscheint rechts, und "Services" wird sichtbar

Gut zu wissen: Unter "Services" finden Sie nach dem Login: Energie-Monitor, Zaehler, E-Mail-Verteiler, Verwaltung, Waschkueche und mehr. Was Sie sehen, haengt von Ihren Berechtigungen ab.

1

Zum Bereich "Passwort aendern" scrollen

Auf der Profilseite sehen Sie: Ihr Avatar-Bild, Gruppen, Zaehler und Persoenliche Daten. Scrollen Sie ganz nach unten zum Abschnitt "Passwort aendern":

Aendert das Passwort fuer Website und Netzwerk-Zugang (SMB/Windows) gleichzeitig.

Mindestens 8 Zeichen

••••••••••

✓

Fertig!

Es erscheint eine gruene Meldung. Ihr neues Passwort gilt sofort fuer:

  • ✔ Die Website (www.rosenweg4303.ch)

Achtung: Falls Sie auf anderen Geraeten (Windows-PC, Netzlaufwerk) noch mit dem alten Passwort angemeldet sind, muessen Sie dort das neue Passwort eingeben.

📄 Dokumente ansehen

Protokolle, Reglemente und Formulare finden

1

Zur Dokumentenablage navigieren

Klicken Sie im Menu auf den Namen Ihrer STWEG (z.B. "STWEG 3"). Auf der STWEG-Seite finden Sie den Bereich "Dokumente".

2

Ordner durchsuchen

Die Dokumente sind in Ordnern organisiert:

📁 01-stammdaten Grundbuch, Reglemente
📁 03-protokolle Sitzungsprotokolle
📁 05-abrechnungen Jahresabrechnungen
📁 99-kontaktdaten Kontaktformulare

Dokument oeffnen oder herunterladen

Klicken Sie auf einen Dateinamen, um das Dokument anzuzeigen. PDF-Dateien werden direkt im Browser geoeffnet. Word/Excel-Dateien werden als Vorschau angezeigt oder heruntergeladen.

⚡ Stromverbrauch pruefen

Ihren aktuellen und vergangenen Verbrauch einsehen

1

Energie-Monitor oeffnen

Klicken Sie im Menu auf "Energie" oder gehen Sie zu:

www.rosenweg4303.ch/energie-monitor.html
2

Ihren Zaehler auswaehlen

Sie sehen nur die Zaehler, die Ihrer Wohnung zugeordnet sind. Waehlen Sie den gewuenschten Zaehler aus der Liste.

3

Verbrauch ansehen

Sie sehen verschiedene Ansichten:

  • • Aktuell: Ihr Verbrauch in Echtzeit (Watt)
  • • Heute: Gesamtverbrauch heute (kWh)
  • • Monat: Monatlicher Verlauf als Grafik
  • • Jahr: Jahresvergleich

Solar-Eigenverbrauch: Wenn Ihre STWEG eine Solaranlage hat, sehen Sie auch den Anteil Solarstrom und die Einsparung.

📶 WLAN verbinden

So verbinden Sie Ihr Geraet mit dem Rosenweg-WLAN

1

WLAN-Name finden

Suchen Sie in den WLAN-Einstellungen Ihres Geraets nach dem Netzwerk:

Rosenweg
2

Passwort eingeben

Ihr persoenliches WLAN-Passwort finden Sie auf der Website unter:

www.rosenweg4303.ch/wlan.html

Dort sehen Sie Ihr Passwort und koennen auch einen QR-Code scannen, um sich automatisch zu verbinden.

QR-Code: Oeffnen Sie die Kamera-App Ihres Smartphones und halten Sie sie auf den QR-Code. Das Geraet verbindet sich automatisch.

✓

Fertig!

Ihr Geraet ist jetzt mit dem Rosenweg-WLAN verbunden. Das Passwort ist pro Gebaeude unterschiedlich und wird vom System automatisch verwaltet.

🖨 Drucken per E-Mail

Dokumente vom Handy oder Computer an den Hausdrucker senden

1

E-Mail senden an den Drucker

Senden Sie Ihr Dokument als E-Mail-Anhang an eine der folgenden Adressen:

druckerr9@rosenweg4303.ch

Drucker im Rosenweg 9 (Erdgeschoss, A4)

druckerr13@rosenweg4303.ch

Drucker im Rosenweg 13 (Erdgeschoss, A3)

2

Dokument als Anhang

Haengen Sie das zu druckende Dokument an die E-Mail an. Unterstuetzte Formate: PDF, Bilder (JPG, PNG), Textdateien.

Kein Anhang? Wenn Sie nur Text in der E-Mail schreiben (ohne Anhang), wird der E-Mail-Text gedruckt.

3

Fuer jemand anderen drucken

Wenn der Ausdruck fuer einen bestimmten Bewohner ist, fuegen Sie den Namen mit + hinzu:

druckerr9+ingrid.limbach@rosenweg4303.ch

→ Es wird automatisch ein Deckblatt mit Name und Adresse gedruckt

✓

Abholen

Holen Sie den Ausdruck beim Drucker ab. Bei persoenlichen Druckauftraegen erhalten der Technische Dienst und der Praesident eine Benachrichtigung.

❓ Haeufige Fragen

Ich habe mein Passwort vergessen. Was tun?

Senden Sie eine E-Mail an technik@rosenweg4303.ch mit Ihrem Namen und Ihrer Adresse. Der Technische Dienst setzt Ihr Passwort zurueck und sendet Ihnen ein neues zu.

Das WLAN funktioniert nicht. Was kann ich tun?
  1. Schalten Sie WLAN an Ihrem Geraet aus und wieder ein
  2. Pruefen Sie ob Sie das richtige Netzwerk "Rosenweg" gewaehlt haben
  3. Pruefen Sie Ihr WLAN-Passwort auf wlan.html
  4. Starten Sie Ihr Geraet neu
  5. Falls das Problem weiterhin besteht: E-Mail an technik@rosenweg4303.ch
Wo finde ich die Protokolle der letzten Sitzung?

Melden Sie sich an, gehen Sie zu Ihrer STWEG-Seite und oeffnen Sie den Ordner "03-protokolle" in der Dokumentenablage. Dort finden Sie alle Sitzungsprotokolle als PDF.

Kann ich die Website auch auf dem Handy nutzen?

Ja! Die Website funktioniert auf allen Geraeten — Handy, Tablet und Computer. Oeffnen Sie einfach www.rosenweg4303.ch in Ihrem Browser.

Tipp: Auf dem iPhone koennen Sie "Zum Home-Bildschirm" waehlen, um ein App-Icon zu erstellen. Auf Android: "Zum Startbildschirm hinzufuegen".

Wer kann meine Daten sehen?

Ihre persoenlichen Daten (Profil, Verbrauchsdaten, Reservierungen) koennen nur Sie selbst und die Verwaltung (Ausschuss / Technik) sehen. Andere Bewohner haben keinen Zugriff auf Ihre Daten.
