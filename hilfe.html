❓ Haeufige Fragen

Ich habe mein Passwort vergessen. Was tun?

Senden Sie eine E-Mail an technik@rosenweg4303.ch mit Ihrem Namen und Ihrer Adresse. Der Technische Dienst setzt Ihr Passwort zurueck und sendet Ihnen ein neues zu.

Das WLAN funktioniert nicht. Was kann ich tun?
  1. Schalten Sie WLAN an Ihrem Geraet aus und wieder ein
  2. Pruefen Sie ob Sie das richtige Netzwerk "Rosenweg" gewaehlt haben
  3. Pruefen Sie Ihr WLAN-Passwort auf wlan.html
  4. Starten Sie Ihr Geraet neu

Melden Sie sich an, gehen Sie zu Ihrer STWEG-Seite und oeffnen Sie den Ordner "03-protokolle" in der Dokumentenablage. Dort finden Sie alle Sitzungsprotokolle als PDF.

Ja! Die Website funktioniert auf allen Geraeten — Handy, Tablet und Computer. Oeffnen Sie einfach www.rosenweg4303.ch in Ihrem Browser.

👤 Mein Profil

Persoenliche Daten, mehrere Telefonnummern und E-Mail-Aliasse, Avatar

💡 Wofuer ist die Profil-Seite?

Hier kannst du selbst deine Stammdaten pflegen — Name, Adresse, mehrere Telefonnummern (Festnetz/Mobil/Geschaeft), E-Mail-Aliasse und einen Avatar. Was du hier eintraegst landet automatisch in der Personen-DB und wird ueberall verwendet wo dein Name/Kontakt benoetigt wird (Verteiler, Reklamationen, Vollmachten etc.).

Was geht da:

  • Mehrere Telefonnummern pro Person (mit Label „Privat", „Geschaeft", „Notfall")
  • Mehrere E-Mail-Adressen + Auswahl der Primaeradresse fuer Benachrichtigungen
  • WhatsApp-Opt-In Toggle — entscheidet ob der Bot dir Mitteilungen schicken darf
  • Passwort aendern (gleichzeitig Website + Netzwerk-Zugang)
  • API-Tokens fuer KI-Agents verwalten (siehe naechste Sektion)

🔐 API-Tokens (PAT)

KI-Agents, Mobile-Apps oder Skripte im eigenen Namen handeln lassen

💡 Wofuer ist das?

Wenn du z.B. Claude Desktop, Hermes, OpenClaw oder ein eigenes Skript hast, das fuer dich Dinge auf der Plattform machen soll (Reklamationen erfassen, Auslagen abfragen, Vollmachten anlegen etc.), erstellst du hier einen Personal Access Token. Der Token handelt dann im Namen deines Users mit deinen Rechten — kein Cloud-Account noetig, kein Passwort-Sharing.

Wie es geht:

  1. Profil → Section „🔐 API-Tokens“ → + Neuen Token erstellen
  2. Name vergeben (z.B. „Claude Desktop"), optional Ablauf + Scopes
  3. Token wird nur einmal angezeigt — Copy-Button drueckt, sicher aufbewahren
  4. Im Agent eintragen als Authorization: Bearer rw_pat_...

Sicherheit: Token verloren → sofort widerrufen, neuen erstellen. Jeder Token kann einzeln widerrufen werden, „letzter Zugriff" zeigt verdaechtige Nutzung.

MCP-Server: Im Repo unter mcp/ gibt's einen fertigen MCP-Server der 52 Tools fuer Claude Desktop / Cursor bereitstellt. README im Verzeichnis.

🔎 KI-Suche

Globale Suche ueber alle Daten mit Claude-Antworten

💡 Wofuer?

Du suchst eine bestimmte E-Mail, einen Handwerker, eine Vollmacht oder erinnerst dich an einen Namen — du tippst einfach den Begriff und die KI sortiert die Treffer nach Relevanz und gibt dir einen Ein-Satz-Kontext.

Wie:

  • Strg + K (Mac: Cmd + K) auf jeder Seite
  • Oder das 🔎-Lupensymbol oben rechts in der Nav
  • Suche durchsucht parallel: Personen, Handwerker, Vollmachten, Reklamationen, E-Mails, Verwaltung, Wohnungen, Projekte

Wichtig: Berechtigungs-aware — du siehst nur Treffer fuer Daten auf die du auch sonst Zugriff hast. Die KI bekommt nicht mehr zu sehen als du selbst.

Umlaut-tolerant: „mueller" findet auch „Mueller" und „Mueller" findet auch „mueller".

📝 Vollmachten

Verwalter, Mieter oder Dritte rechtsverbindlich bevollmaechtigen

💡 Wofuer?

Als Eigentuemer kannst du Personen schriftlich beauftragen, dich in bestimmten Belangen zu vertreten — z.B. die Hausverwaltung in laufenden Verwaltungs-Sachen, einen Mieter fuer Schluesselverwaltung oder einen Anwalt fuer Einzelgeschaefte. In der Schweiz braucht's dafuer Schriftform.

Arten von Vollmachten:

  • Generell — laufende Verwaltung, unbefristet bis Widerruf
  • Spezifisch — nur ein konkretes Geschaeft (z.B. Verkauf)
  • Auskunft — nur Belegeinsicht, kein Entscheidungsrecht

Workflow:

  1. Erfassen mit „+ Neue Vollmacht erteilen" (Quick-Pick aus Objektverwaltung-Kontakten oder Verwaltungs-Firmen)
  2. Vorlage aus dem Vorlagen-Tab uebernehmen (Geltungsbereich-Texte vom Praesidium vorgegeben)
  3. Digital signieren via Authentik-Login (ZertES Art.2 einfache el. Signatur) ODER
  4. PDF drucken → unterschreiben → scannen → Signierte PDF hochladen
  5. Optionale KI-Pruefung: Claude prueft ob alle Namen unterschrieben sind und nichts manipuliert wurde

Bei Miteigentum: ALLE Eigentuemer muessen einzeln signieren — wird im PDF mit eigenem Unterschriftsfeld geklaert.

Auto-Vorbereitung: Wenn ein Verwalter in der Objektverwaltung als Kontakt hinzukommt, wird automatisch ein Vollmachts-Entwurf erstellt. Du musst nur noch signieren.

🔐 Mein Zugang (ISP)

VPN-Konten, eigene VLAN-Antraege, Reverse-Proxy-Routen

💡 Wofuer?

Die Rosenweg-Kooperation betreibt ihr eigenes Internet/Netzwerk (Init7-Glasfaser, UDM-Pro). Als Bewohner kannst du dir Remote-Zugriff (VPN) einrichten, eigene VLANs beantragen (fuer Smart-Home, Server, Lab) oder eigene Web-Services via unseren zentralen Reverse-Proxy ins Internet stellen lassen.

Bereiche:

  • VPN-Konten — selbst anlegen, WireGuard/Netbird/Tailscale. Konfiguration zurueckverlangen via Antrag.
  • VLAN beantragen — eigenes Subnetz mit konfigurierbarer Groesse (/29 bis /24), Internet-Zugriff togglen, Status-Verfolgung
  • Reverse-Proxy-Routen — eigene Domain durch unseren zentralen Proxy schicken, Authentik-Auth dazwischen schalten optional

🔗 Mein Zugang →

🌐 VLAN beantragen

Eigenes Netz-Segment fuer Smart-Home, Server, Gaming etc.

💡 Wofuer?

Du willst deine IoT-Geraete vom Rest deines Netzes trennen? Einen Server betreiben? Mehrere Gaming-Konsolen ohne UPnP-Chaos? Ein eigenes VLAN ist die saubere Loesung.

Antrag stellen:

  1. Auf Mein Zugang → „VLAN beantragen"
  2. Zweck angeben (Pflicht — wofuer wird's gebraucht), Wunsch-Name, Groesse (Geraeteanzahl), Internet-Zugriff ja/nein
  3. Technik prueft + entscheidet. Bei Genehmigung: VLAN-ID + Subnetz zugewiesen, deployed.

Status: pending → approved (mit VLAN-ID) → deployed. Bei Ablehnung gibt's einen Grund.

🔁 Reverse-Proxy

Eigene Web-Services ins Internet veroeffentlichen

💡 Wofuer?

Du hostest zu Hause eine Nextcloud, einen Home-Assistant, Bitwarden oder ein Game-Server-Dashboard und willst es von ausserhalb erreichbar machen — ohne dass du selbst Domain, SSL und Firewall basteln musst. Du gibst nur deinen internen Backend-URL an, der Rest ist automatisch (Let's-Encrypt-Cert, Cloudflare-Tunnel optional, Authentik-Auth optional).

Workflow:

  1. Antrag mit gewuenschtem Hostname (z.B. cloud.mein-name.rosenweg4303.ch oder externe Domain) + Backend-URL
  2. System checkt: wenn Hostname „rosenweg" enthaelt → Admin-Pruefung; sonst Auto-Approval per DNS-Check
  3. Bei externer Domain: DNS auf public.rosenweg4303.ch setzen (CNAME) oder die public IP (A). System prueft alle 5 Min, sobald korrekt → auto-aktiv.

Features: SSL via Let's Encrypt, optional Authentik-Auth davor (Login-Pflicht), Rate-Limiting, public via Cloudflare-Tunnel oder intern-only.

↪ Adress-Umleitung

HTTP 301/302 von einer URL zur anderen

💡 Wofuer?

Du hast eine alte Domain die auf eine neue zeigen soll (alt.example.ch → new.example.ch) oder willst eine bestimmte URL auf eine andere weiterleiten. Anstatt selbst einen Webserver zu betreiben, traegst du's hier ein und der zentrale Proxy macht das fuer dich.

Antrag: Source-Host + Target-URL + HTTP-Code (301 dauerhaft / 302 temporaer) + „Path erhalten?" (ob /foo auch an target/foo angehaengt wird). DNS-Check + Auto-Approval wie bei Reverse-Proxy.

✉ Mailserver & PMG

Eigene Domain durch Proxmox-Mail-Gateway filtern lassen

💡 Wofuer?

Du betreibst selbst einen Mailserver (Mailcow, dovecot, Microsoft 365 etc.) und willst von Rosenweg's Proxmox Mail Gateway die Spam- und Virus-Filterung uebernehmen lassen. Bei uns wird gefiltert, bei dir wird ausgeliefert. PMG hat keine eigenen Mailboxen — er ist nur Filter.

Setup:

  1. Im ISP-Admin / „Mailserver/PMG"-Tab deine Domain eintragen + Target-Host (wohin PMG nach Filterung weiterleitet)
  2. DNS-MX-Record fuer deine Domain auf public.rosenweg4303.ch setzen
  3. Auto-Check prueft den MX-Record, wenn korrekt → aktiviert
  4. Optional: DKIM-Selector + Key fuer Signing on the way out

Status PMG: aufgesetzt im LXC CT 230 (100.64.2.31), Web-UI verfuegbar. Filter-Schaerfe konservativ eingestellt (eher durchlassen).
