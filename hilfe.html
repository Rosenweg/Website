👤 Mein Profil

Persoenliche Daten, mehrere Telefonnummern und E-Mail-Aliasse, Avatar

💡 Wofür ist die Profil-Seite?

Deine Profil-Seite ist die einzige Stelle wo deine persoenlichen Stammdaten gepflegt werden. Was du hier eintraegst (Name, Telefon, E-Mail, Adresse, Avatar) wird ueberall verwendet: in der Personen-Datenbank, in Verteiler-Mails an dich, in Reklamationen, in Vollmachten, im Telefonbuch, sogar im WhatsApp-Bot für die Wer-bist-du-Erkennung. Du wirst hier auch dein Passwort ändern, deine API-Tokens verwalten und entscheiden ob der WhatsApp-Bot dich kontaktieren darf.

Was du auf der Profil-Seite findest

Click auf den Avatar-Kreis → Bild hochladen (max 2 MB, JPG/PNG). Wird ueberall als dein „Gesicht" angezeigt. Name + Adresse stehen darunter, vom Ausschuss gepflegt — bei Aenderungswunsch: technik@rosenweg4303.ch.

Du kannst beliebig viele Nummern hinterlegen. Pro Nummer: Typ (Privat/Geschaeft/Mobil/Festnetz/Notfall) + Label (Freitext, optional) + Nummer im Format +41 79 .... Wenn der Bot dich kennen soll: WhatsApp-Nummer hier eintragen + Opt-In aktivieren.

✉ E-Mail-Adressen (mehrere)

Primaere Adresse für Authentik + Benachrichtigungen, dazu beliebig viele Aliasse. Beispiel: Stefan privat: stefan@gmail.com, Stefan geschaeftlich: stefan@firma.ch. Mails an Verteiler gehen an die Primaere.

🔐 API-Tokens (PAT)

KI-Agents, Mobile-Apps oder Skripte im eigenen Namen handeln lassen

💡 Wofür ist das?

Wenn du Anwendungen wie Claude Desktop, Hermes, OpenClaw, n8n, ein selbst geschriebenes Skript oder eine Mobile-App hast, die für dich Dinge auf der Plattform erledigen soll (Reklamationen erfassen, Auslagen abfragen, Vollmachten anlegen, …), brauchst du einen Weg, dich dort einzuloggen ohne Authentik-Browser-Login. Genau dafuer sind Personal Access Tokens (PAT). Der Token wirkt wie ein Passwort, aber speziell für Maschinen — und im Gegensatz zum Passwort kannst du beliebig viele anlegen, jedes mit eigenem Namen, eigenen Rechten und einzeln widerrufbar.

🎯 Typische Use-Cases

  • Claude Desktop via MCP — du fragst „Wer ist der Sanitaer-Handwerker?“ und Claude antwortet mit den Daten aus dem Handwerker-Verzeichnis
  • Mobile-App / Shortcuts — „Hey Siri, melde Schaden ‘Aufzug Haus 9 steht still’“ legt eine Reklamation an
  • Eigenes Dashboard auf einem Raspberry Pi das alle 5 Min die offenen Reklamationen zeigt
  • n8n / Zapier-Automation die bei jeder neuen Auslage eine Telegram-Meldung schickt
  • Mini-Skript das nachts deine Wohnungs-Stromverbraeuche ausliest und in eine Excel-Tabelle schreibt

Schritt-für-Schritt: Token erstellen

  1. Profil oeffnen → profil.html → zur Sektion 🔐 API-Tokens scrollen.
  2. + Neuen Token erstellen klicken → Modal oeffnet sich. Du siehst:
    Name * — z.B. „Claude Desktop“, „n8n Auslagen-Bot“, „Mein Pi Dashboard“
    Gültigkeit — 7 Tage / 30 / 90 / 365 / unbegrenzt
    Scopes — was darf der Token? Default leer = alle deine Rechte. Sonst Checkboxen wie vollmachten:read, handwerker:read etc.
  3. Erstellen → der Token erscheint in einem gruenen Banner:
    rw_pat_5ec5161fe155adf583de1182bce7948b17570e6c35e6d1fb862c3a370998ee84 ⚠ Wird NUR EINMAL angezeigt — Copy-Button drücken, dann in deinen Passwort-Manager oder direkt in die Agent-Config einkleben.
  4. Im Agent verwenden: jedes API-Tool akzeptiert den Token als HTTP-Header: Authorization: Bearer rw_pat_5ec5161fe...

🤖 Quick-Setup: Claude Desktop mit MCP-Server

Im Repo gibt's einen fertigen MCP-Server der 52 typisierte Tools bereitstellt — Vollmachten, Auslagen, Reklamationen, Handwerker, Wohnungen, Mail, Energie etc. Setup:

  1. Repo clonen: git clone https://github.com/Rosenweg/Website
  2. cd Website/mcp && npm install
  3. ~/Library/Application Support/Claude/claude_desktop_config.json bearbeiten:
{
  "mcpServers": {
    "rosenweg": {
      "command": "node",
      "args": ["/Pfad/zu/Website/mcp/src/index.js"],
      "env": {
        "ROSENWEG_TOKEN": "rw_pat_DEIN_TOKEN_HIER"
      }
    }
  }
}

Claude Desktop neu starten → im Tools-Menue siehst du die Rosenweg-Tools. Dann z.B. fragen: „Welche offenen Reklamationen gibt es in STWEG 3?“

🛡 Sicherheits-Regeln (wichtig!)

  • Token sind Passwoerter — nie in Chat, Git-Repos oder ungeschuetzten Configs ablegen
  • Bei Verlust sofort im Profil widerrufen (roter Button) und neuen Token erstellen
  • „Letzte Nutzung“ regelmässig prüfen — ungewoehnliche IP oder Zeit? → widerrufen
  • Scopes nutzen wenn möglich — ein Read-Only-Token kann keinen Schaden anrichten
  • Ablauf setzen wenn der Use-Case begrenzt ist (z.B. nur 30 Tage für einen einmaligen Datenexport)

❓ Haeufige Fragen

Kann der Token mehr als ich?

Nein. Der Token bekommt exakt die Rechte deines Authentik-Accounts. Du bist Bewohner ohne Ausschuss-Rechte? Dann kann der Token auch keine Reklamationen anderer User ändern.

Warum Scopes wenn ich der Token-Besitzer eh alles kann?

Damit ein kompromittierter Token NICHT alles kann. Beispiel: dein MCP-Token kann nur handwerker:read — wird er geklaut, kann der Angreifer keine Vollmacht in deinem Namen erstellen.

Ich sehe in „Letzte Nutzung“ eine fremde IP — was tun?

SOFORT widerrufen (roter Button). Pruef ob du den Token versehentlich exponiert hast (Git-Commit, Screenshot, etc.). Authentik-Passwort vorsichtshalber auch ändern. Bei Verdacht auf Missbrauch: technik@rosenweg4303.ch informieren — wir sehen im Audit-Log was passiert ist.

Wie viele Tokens darf ich haben?

Keine harte Grenze. Pro Anwendung einen eigenen Token ist Best-Practice (besser nachvollziehbar wer wann was tat).

🔎 KI-Suche

Globale Suche über alle Daten mit Claude-Antworten

💡 Wofür ist das?

Stell dir vor du suchst eine bestimmte E-Mail, einen Handwerker oder die Vollmacht von vor 3 Monaten — statt 4 verschiedene Seiten aufzurufen und in jeder zu filtern, tippst du Strg+K, schreibst was du suchst und Claude sortiert dir die Treffer nach Relevanz und liefert einen Satz Kontext oben drauf. Es ist der schnellste Weg zu einer Information wenn du nicht genau weisst wo sie liegt.

🚀 So oeffnest du die Suche

  • Strg + K (Mac: Cmd + K) auf jeder Seite der Rosenweg-Website
  • Oder klick auf das 🔎 Lupen-Icon oben rechts in der Navigation
  • Esc schliesst die Suche wieder

✅ Was wird parallel durchsucht?

❓ FAQ

Was ist ein Schaden in der STWEG vs. in meiner Wohnung?

Gemeinschaftsbereich (Treppe, Aufzug, Heizung, Fassade, Dach, Garten, Tiefgarage): STWEG-Reklamation. In deiner Wohnung (Wasserhahn, Steckdose, Boden): grundsätzlich Eigentümer-Sache. Im Zweifel: trotzdem melden, der Ausschuss klärt.

Wie schnell wird reagiert?

Notfaelle (Wasserschaden, Aufzug, Heizungsausfall im Winter): innerhalb von 1-2 Stunden. Normale Reklamationen: 1-3 Tage. Sehr klein (Lampe ersetzen): kann auch laenger dauern. Bei Notfall ZUSAETZLICH zur Reklamation den Bereitschaftsdienst-Handwerker direkt anrufen — Nummern via /notfall im WhatsApp-Bot.

Kann ich eine Reklamation zurückziehen?

Nicht direkt, aber du kannst dem Ausschuss schreiben (E-Mail an ausschuss@rosenweg4303.ch oder Kommentar), dann markieren sie's als abgewiesen mit Grund „zurueckgezogen vom Melder“.

Wer sieht meine Reklamation?

Der Ausschuss deiner STWEG, Präsident, Technik und der zugewiesene Handwerker (nur Text + Foto, kein Person-Match). Andere Bewohner sehen Reklamationen NICHT, auch nicht in der KI-Suche.

📝 Vollmachten

Verwalter, Mieter oder Dritte rechtsverbindlich bevollmaechtigen

💡 Wofür ist das?

Im Stockwerkeigentum gibt es viele Situationen wo du als Eigentümer nicht selbst handelst, sondern jemand für dich handeln soll — die Hausverwaltung in laufender Verwaltung, ein Mieter der die Schluesselverwaltung uebernimmt, ein Anwalt für einen Vertragsabschluss, ein Familienmitglied wenn du im Spital bist. In der Schweiz braucht jede Vollmacht Schriftform — entweder handschriftlich unterzeichnet auf Papier oder qualifizierte elektronische Signatur. Diese Plattform unterstuetzt beide Wege.

📚 Die drei Arten im Detail

1. Generelle Vertretungs-Vollmacht

Bevollmächtigter darf dich in allen Belangen der laufenden Verwaltung vertreten. Typisch für die Hausverwaltung: Mietvertraege abschliessen, Reparaturen bis CHF X beauftragen, Mietzins entgegen nehmen, Korrespondenz fuehren. Gilt bis Widerruf. Was NICHT erlaubt ist: Verkauf der Wohnung, ausserordentliche Aufwendungen über Limit, Stimmrecht an STWEG-Versammlung (dafuer brauchst du eine separate Stimmrechtsvollmacht).

2. Spezifische Vollmacht (Einzelgeschaeft)

Nur für eine einzelne klar definierte Sache. Z.B. „Anwalt darf den Mietvertrag mit Familie XY abschliessen“ oder „Familienmitglied darf einmalig den Schlüssel übergeben“. Sobald die Sache erledigt ist, ist die Vollmacht ausgeschoepft.

3. Datenschutz- / Auskunftsvollmacht

Bevollmächtigter darf nur Einsicht in deine Belege, Abrechnungen und Verträge nehmen — keine Entscheidungen in deinem Namen. Typisch wenn du jemandem Zugang zu deinem Fall geben willst (z.B. Steuerberater, neugieriger Verwandter) ohne ihm Handlungsmacht zu geben.

Workflow: Vollmacht erstellen

  1. Auf /vollmachten.html → + Neue Vollmacht erteilen
  2. Bevollmächtigter wählen — drei Optionen:
    • Person aus Objektverwaltung — Quick-Pick zeigt alle Kontakte deiner Wohnungen (Miteigentuemer, Mieter, Verwalter etc.) farbig nach Rolle. Klick → Daten autom. übernommen.
    • Verwaltung (Firma) — Dropdown mit hinterlegten Hausverwaltungen (z.B. langPartners)
    • Externe Person — manuell Name/E-Mail/Adresse eintragen (z.B. Anwalt aus Basel)
  3. Art & Geltungsbereich — Art auswaehlen (generell / spezifisch / auskunft). Im Geltungsbereich-Textfeld konkret beschreiben was erlaubt ist. Tipp: Im Tab „Vorlagen“ gibt es vorbereitete Standard-Texte vom Praesidium (z.B. „Generelle Verwalter-Vollmacht mit CHF 1'000 Limit“) — einfach übernehmen und ggf. anpassen.
  4. Wohnungsbezug (optional aber empfohlen) — eine bestimmte Wohnung deiner Liste oder eine ganze STWEG. Damit ist klar für welches Objekt die Vollmacht gilt.
  5. Gültigkeit — Datum von / bis. Bei „bis“ leer = unbefristet bis Widerruf.
  6. Als Entwurf speichern — jetzt ist die Vollmacht angelegt, aber NOCH NICHT GUELTIG. Erst die Signatur macht sie wirksam.

⚠ Wichtig: Miteigentum

Schweizer Recht: bei mehreren Eigentuemern (Ehepaar, Erbengemeinschaft, GbR, …) müssen ALLE einzeln signieren, damit die Vollmacht wirksam ist.

Im Modal kannst du beliebig viele Vollmachtgeber hinzufügen — entweder per Quick-Pick aus den Objektverwaltungs-Kontakten oder manuell. Im generierten PDF erscheint pro Person ein eigenes Unterschriftsfeld + ein Hinweis „Bei Miteigentum müssen alle X Vollmachtgeber unterschreiben“. Sobald die letzte fehlende Person signiert hat, wird der Status automatisch auf „aktiv“ gesetzt.

✅ Digital signieren

🔐 1. VPN-Konten

💡 Wofür?

Du bist im Urlaub und willst von ueberall auf deinen Home-Server zugreifen? Oder auf interne Rosenweg-Dienste die nicht oeffentlich erreichbar sind? Ein VPN macht's möglich.

Drei Backends unterstuetzt:

  • WireGuard — modern, schnell, am wenigsten Setup. Empfohlen wenn du selbst deinen Key generieren kannst.
  • Netbird — Mesh-VPN, einfaches Onboarding via App, ueberlebt Netzwechsel
  • Tailscale — auch Mesh, kommerziell, sehr poliert. Eigener Account erforderlich.

Workflow:

  1. Auf /isp-mein-zugang.html → + Neues VPN-Konto
  2. Backend wählen (WireGuard / Netbird / Tailscale)
  3. Bei WireGuard: Public-Key generieren (auf eigenem Gerät mit wg genkey | tee privatekey | wg pubkey) und eintragen. Private-Key behaeltst DU.
  4. Speichern. Technik konfiguriert serverseitig und teilt dir IP zu.
  5. Du bekommst per E-Mail die Konfig (WireGuard: .conf-File, Netbird: Invite-Link, Tailscale: ACL-Eintrag).
  6. Konfig auf deinem Gerät importieren → verbunden.

🌐 2. VLAN beantragen

💡 Wofür?

Ein VLAN (Virtual LAN) ist ein eigenes isoliertes Sub-Netz. Konkrete Use-Cases:

  • Smart-Home VLAN — alle deine Shellys, Lampen, Thermostate in einem eigenen Netz das nicht ins Internet darf (Privacy + Security)
  • Gaming-VLAN — alle Konsolen, weniger UPnP-Chaos im Haupt-Netz, optional QoS-Priorisierung
  • Lab-VLAN — du bastelst an Servern, willst Crashes nicht auf dein normales Netz auswirken
  • Mieter-VLAN — getrennter Internet-Zugang für Untermieter ohne Zugriff auf dein eigenes Netz

Antrag stellen:

  1. + VLAN beantragen klicken → Formular mit:
  2. Zweck (Pflicht) — ein Satz wofür du das brauchst. Beispiel: „Smart-Home-Geräte getrennt vom Haupt-Netz halten, mit Internet aber ohne Zugriff aufs Privat-VLAN.“
  3. Wunsch-Name — freiwillig (z.B. „SmartHome")
  4. Gewuenschte Groesse — /29 (6 nutzbare IPs), /28 (14), /27 (30), /24 (254). Wenn du nicht sicher bist: /29 reicht meistens für Smart-Home.
  5. Geräte-Anzahl — grobe Schaetzung
  6. Internet-Zugriff (Checkbox)
  7. Andere VLANs (Checkbox) — soll dein VLAN auf andere zugreifen können (z.B. dein Haupt-Netz)?

Antrags-Lebenszyklus

1. pending

Antrag eingereicht, Technik prüft. Du wartest auf Entscheidung.

2. approved

Technik hat genehmigt, VLAN-ID + Subnet zugewiesen. Wartet auf Deployment.

3. deployed

VLAN ist auf UDM-Pro konfiguriert + auf den Switches. Du bekommst die Anbindungs-Anleitung (Port auf welchem Switch, welcher Tag).

rejected

Mit Begründung (z.B. Konflikt, Sicherheitsbedenken). Du kannst angepasst neu beantragen.

🔁 3. Reverse-Proxy-Routen

💡 Wofür?

Du hostest zu Hause eine Nextcloud, einen Home-Assistant, Bitwarden, ein Game-Server-Dashboard oder eine persoenliche Webseite und willst's von ausserhalb erreichbar machen — ohne selbst Domain, SSL-Zertifikat, Firewall-Regeln und Authentik-Integration basteln zu müssen. Du gibst nur deinen internen Backend-URL an, der Rest ist automatisch.

🔹 Auto-Approval mit Hostname-Prüfung

Bei Antrag prüft das System den Hostname:

  • Enthaelt „rosenweg“ oder Pattern r<Nummer>. (wie r9., r17.) → pending_admin — Technik muss manuell prüfen
  • Endet auf rosenweg4303.ch / rosenweg9.ch → pending_admin
  • Beliebige andere Domain → sofortiger DNS-Check, bei Match → automatisch aktiviert

So konfigurierst du eine Route für eigene Domain (z.B. test.abc.ch):

  1. + Route hinzufügen → Modal oeffnet sich
  2. System zeigt dir die DNS-Konfig die du machen musst: 
    A:    37.17.232.133
CNAME (Alternative): public.rosenweg4303.ch
    Diese Werte trag bei deinem Domain-Provider (Cloudflare, Infomaniak, Hostpoint etc.) ein.
  3. In Modal: Hostname (z.B. test.abc.ch), Backend-URL (z.B. http://10.0.50.5:8080), Optionen public/SSL/Auth-required.
  4. Speichern → System prüft DNS sofort. Wenn dein DNS-Record bereits korrekt zeigt: sofort aktiviert. Sonst: pending_dns, System prüft alle 5 Minuten erneut.
  5. Sobald DNS passt + Approval ok: dein Backend ist via https://test.abc.ch erreichbar, SSL-Cert von Let's Encrypt automatisch.

🛡 Optional: Authentik-Auth davor

Wenn du „auth_required“ aktivierst, wird vor deinem Backend ein Authentik-Login geschaltet. Nur authentifizierte Rosenweg-User können zugreifen. Praktisch wenn du z.B. dein internes Wiki teilen willst aber nicht der ganzen Welt.

FAQ über alle drei Bereiche

Kostet das was?

VPN-Konten: gratis. VLAN-Anträge: gratis (Aufwand bei komplexen Erschliessungs-Änderungen nach Aufwand). Reverse-Proxy-Routen: gratis. Externe Domain-Registrierung musst du selbst bezahlen.

Wie schnell wird ein VLAN deployed?

Approval idR 1-3 Tage. Deployment je nach Komplexitaet: einfache VLAN-Hinzunahme über Nacht, mit Switch-Anbindung kann's eine Woche dauern (Hardware-Konfiguration).

Was passiert wenn ich auszieh?

VPN-Konten + Reverse-Proxy-Routen werden inaktiv geschaltet, nach 30 Tagen geloescht (analog Authentik-Konto). VLAN bleibt bestehen falls noch Bewohner es nutzen, sonst aufgeloest.

Wie wird Missbrauch verhindert?

Rate-Limiting auf Reverse-Proxy-Routen einstellbar. Verdaechtige Aktivitaet wird im Cloudflare/Traefik-Log sichtbar. Bei Missbrauch sperrt Technik die Route.

✉ Mailserver & PMG

💡 Wofür?

Du betreibst selbst einen Mailserver (Mailcow, dovecot, Microsoft 365 etc.) und willst von Rosenweg's Proxmox Mail Gateway die Spam- und Virus-Filterung übernehmen lassen. Bei uns wird gefiltert, bei dir wird ausgeliefert. PMG hat keine eigenen Mailboxen — er ist nur Filter.

Setup:

  2. DNS-MX-Record für deine Domain auf public.rosenweg4303.ch setzen
  3. Auto-Check prüft den MX-Record, wenn korrekt → aktiviert
  4. Optional: DKIM-Selector + Key für Signing on the way out

🔌 Virtuelles Shelly (PV-Ueberschuss)

Smart-Home-Steuerung anhand des Solar-Ueberschusses

💡 Wofür ist das?

Die Solaranlage von STWEG3 (Rosenweg 9) liefert Live-Daten als virtuelles Shelly Pro 3EM Energiemessgeraet ins Heimnetz. Damit kannst du in der Shelly-App, Home-Assistant, Node-RED etc. Automationen anlegen: Wallbox laden wenn Ueberschuss da ist, Klima nur wenn Solar laeuft, Pool-Pumpe ueberschuss-gesteuert — ohne dass du selbst eine Solar-API anzapfen musst.

🚀 Ready-to-Use Backend-URLs

Diese URLs kannst du direkt in deinem Shelly-Script (Variante A) oder Emulator (Variante B) als BACKEND_URL eintragen. Jede Variante mappt 3 Werte auf die 3 Phasen des virtuellen Geraets:

⚡ PV-Ueberschuss (Default)

https://www.rosenweg4303.ch/api/energy/shelly?variant=surplus
  • Phase A = Ueberschuss ohne Boiler (was real ins Netz geht)
  • Phase B = Ueberschuss mit Boiler (was verfuegbar wäre wenn Heizstab aus)
  • Phase C = aktuelle Heizstab-Last

Typischer Use-Case: Wallbox/Klima nur einschalten wenn Phase B > Schwellwert.

☀ Solar-Produktion & Verbrauch

https://www.rosenweg4303.ch/api/energy/shelly?variant=production
  • Phase A = Solar-Produktion in Watt
  • Phase B = Verbrauch im Haus
  • Phase C = Netz-Bezug (nur Bezug, ohne Einspeisung)

Typischer Use-Case: Dashboard das anzeigt „produzierst du gerade mehr als du verbrauchst?“

🔌 Netz-Flussrichtung (Einspeisung/Bezug)

https://www.rosenweg4303.ch/api/energy/shelly?variant=grid
  • Phase A = Einspeisung ins Netz (W, immer ≥0)
  • Phase B = Netz-Bezug (W, immer ≥0)
  • Phase C = Netto-Bilanz (positiv = Bezug, negativ = Einspeisung)

Typischer Use-Case: Reine Netz-Bilanz visualisieren ohne Zwischenrechnung.

Direkt anschauen was kommt: URL in den Browser kopieren → JSON-Antwort. Update-Frequenz: ~5 Sekunden im Backend, du pollst alle 10-30s.
