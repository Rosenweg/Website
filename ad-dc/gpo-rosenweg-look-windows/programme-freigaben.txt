# ============================================================================
# Die Programme selbst werden auf /stationen gepflegt ("Windows-Programme",
# fuer alle und je Rechner unter "Einstellen ..."); dort gehen aber nur Orte
# unter C:\Program Files. Diese Datei ist fuer alles ausserhalb, mit Review
# im Git statt per Klick. Erlaubt ist ohnehin: C:\Windows, die
# Defender-Plattform und (im Grundschutz) alles unter Programme.
#
# Eine Zeile je Ordner oder Datei, * am Ende fuer alles darunter. NUR Orte,
# die normale Benutzer NICHT beschreiben koennen - ein freigegebener Ordner,
# in den jeder schreiben darf, hebelt die ganze Liste aus. Danach auf dc1
# ./einrichten.sh, wirkt beim naechsten Start.
#
# Beispiel:
# C:\Tools\Steuerprogramm\*
