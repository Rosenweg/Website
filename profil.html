🔑 API-Tokens

Persönliche Zugriffstokens für KI-Agents, Mobile-Apps oder eigene Skripte. Token handelt im Namen des Users mit dessen Rechten. Sicher behandeln — wie ein Passwort.

Wie verwende ich einen Token?

Sende den Token als Authorization: Bearer rw_pat_… Header bei jedem API-Aufruf.

Beispiel: curl -H "Authorization: Bearer rw_pat_xxx" https://www.rosenweg4303.ch/api/me

Für MCP/Hermes/OpenClaw: Token in der Agent-Konfiguration eintragen, der Agent setzt den Header automatisch.

🧰 Agent verbinden

Claude und andere Assistenten können das Portal über mcp.rosenweg4303.ch bedienen — mit deinem Token, in deinen Rechten. Freie Werkzeuge (Waschküche, Schadensmeldung, Adressmutation) laufen sofort; alles, was sendet, öffnet oder löscht, fragt zuerst.

Claude Code:

claude mcp add rosenweg --transport http https://mcp.rosenweg4303.ch --header "Authorization: Bearer rw_pat_…"

Claude Desktop / andere Clients (mcpServers):

{ "rosenweg": { "type": "http", "url": "https://mcp.rosenweg4303.ch",
               "headers": { "Authorization": "Bearer rw_pat_…" } } }

Erstellst du oben einen Token, erscheint er hier eingesetzt — nur solange die Seite offen ist. Welche Werkzeuge ein Token sieht, bestimmen seine Scopes; ohne Scopes sieht er alle, die dir zustehen.
