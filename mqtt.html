Topic-Schutz-Regeln (beliebige Topics → Gruppe)

Gib einer Authentik-Gruppe Lesen und/oder Schreiben auf beliebige Topics. Gilt zusätzlich zur energy/-Zähler-Logik. Technik darf immer alles.

❓ Wie funktionieren Topics und die Platzhalter + und #?

Ein Topic ist wie ein Ordner-Pfad, mit / getrennt — z.B. energy/r9/2og3/power_w = Haus r9 → Wohnung 2og3 → Leistung.

# = alles ab hier (diese Ebene und alle darunter). Steht immer am Ende.
control/r9/# → control/r9 und alles darunter (control/r9/heizung, control/r9/licht/flur …).
energy/# → wirklich alle Energie-Topics.

+ = genau eine Ebene (ein Platzhalter mittendrin).
energy/+/haupt → der haupt-Zähler jedes Hauses (r1, r9, …), aber nichts tiefer.

Ohne Platzhalter = genau dieses eine Topic, z.B. control/r9/heizung.

Faustregel: „eine Gruppe darf einen ganzen Bereich" → bereich/#. Im Zweifel # am Ende nehmen.
