🔧 Einrichtung

  1. WHATSAPP_SHARED_SECRET in .env setzen (gleicher Wert wie bei API)
  2. Service starten / neu starten: docker service update --force rosenweg_whatsapp-bot
  3. QR-Code aus Logs holen: docker service logs -f rosenweg_whatsapp-bot
  4. Auf einem Smartphone mit gewünschter WhatsApp-Nummer: Einstellungen → Verknüpfte Geräte → Gerät verknüpfen → QR scannen
  5. Bot ist bereit, sobald "[WA] Bot ist bereit" im Log erscheint
