Linphone einrichten

Am Telefon: Linphone öffnen → Assistent → „Fetch Remote Configuration" → QR-Code scannen. Danach ist Konto, Transport und Rufnummer gesetzt — nichts abzutippen.
Am Telefon: QR-Code mit der Kamera scannen → der Browser lädt androidsip-<ext>.xml in „Downloads". Dann Android SIP öffnen → ⋮ → Import → Downloads → Datei wählen. Danach unter „System Calling Accounts" das Konto aktivieren. Die Datei danach aus Downloads löschen — sie enthält das SIP-Passwort.
📇 Telefonbuch — einmalig in der App eintragen
Das synchronisierte Adressbuch ist in Linphone eine „FriendList" und liegt in der App-Datenbank, nicht in der Konfigurationsdatei — es lässt sich deshalb nicht per QR mitliefern. Einmal pro Gerät: Einstellungen → Kontakte → CardDAV-Adressbuch hinzufügen.
Der Link enthält das SIP-Passwort und gilt nur einmal. Wird er nicht benutzt, verfällt er von selbst.
